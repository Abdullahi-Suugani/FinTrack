# Personal Finance Tracker

A full-stack Personal Finance Tracker that helps users manage their income and expenses, organize transactions by category, view monthly financial summaries, and manage their profile.

The application includes JWT authentication, role-based authorization, an admin dashboard, profile-picture uploads, API validation, Swagger documentation, and a MongoDB database.

## Features

### Authentication

- User registration
- User login
- JWT authentication
- Password hashing with bcrypt
- Get authenticated user profile
- Protected routes
- Role-based authorization

### Transactions

- Create transactions
- View transactions
- Update transactions
- Delete transactions
- Support for income and expenses
- Transaction categories
- Transaction dates
- Monthly financial summaries

### Categories

- View available transaction categories
- Assign categories to transactions

### Profile

- View user profile
- Upload profile picture
- Cloudinary image storage

### Admin Dashboard

- Admin-only dashboard
- View financial statistics
- View user and transaction information
- Top spending categories
- Protected admin API

### Security

- JWT authentication
- bcrypt password hashing
- Zod validation
- Helmet
- CORS
- Rate limiting
- Centralized error handling
- Environment variables for secrets

### API Documentation

Swagger UI is available for testing and exploring the REST API.
